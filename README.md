# TwentyThirdCentury website starter

A responsive single-page prototype for a youth-oriented technology and hope-focused hub.

## Run
Open `index.html` in a modern browser. No build step required.

## Current features
- Responsive landing page
- Three scripted AI specialist demos (Nova, Byte, Sol); not live model inference
- Technology topic cards linking to established sources
- A 20-second click game
- Blog and music discovery links
- Supportive wellbeing copy and a South African emergency note

## Before a public launch
This is a front-end prototype. It has no backend, accounts, database, real AI API, live trending feeds, streaming integration, community publishing or moderation system. Connect AI through a server-side API (never expose API keys in browser JavaScript). Add privacy/security review, accessibility testing, content moderation, abuse reporting, terms/privacy pages, and appropriate safeguarding before collecting data or enabling community features.

## Publish
Deploy `index.html` as a static website using GitHub Pages, Netlify, or Cloudflare Pages. For a custom domain, configure DNS with your domain provider. Publishing requires access to the hosting account.
